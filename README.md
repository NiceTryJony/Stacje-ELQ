# Stacje-ELQ Bot

Простой Telegram-бот для сбора точек (координаты + название + описание).

## Запуск

1. Получи токен у @BotFather в Telegram.
2. Установи зависимости:
   ```
   pip install -r requirements.txt
   ```
3. Укажи токен одним из способов:
   - через переменную окружения: `export BOT_TOKEN=твой_токен`
   - либо впиши его напрямую в `bot.py` вместо `PASTE_YOUR_TOKEN_HERE`
4. Запусти:
   ```
   python bot.py
   ```

При первом запуске бот сам импортирует 115 станций из `stacji-elq-import.json`
в рабочий файл `stacje_elq_data.json` (дальше работает уже с ним).

## Команды

- `/add` — добавить станцию (геометка или текст `52.7086, 17.4234`, потом название, потом описание — или «Пропустить»)
- `/list` — список всех станций с координатами
- `/count` — сколько станций в базе

## Файл данных

`stacje_elq_data.json` — тот же формат, что и исходный экспорт, можно открывать
и редактировать вручную.
